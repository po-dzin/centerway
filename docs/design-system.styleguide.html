Семантическая ДС: смысл, а не мода

Токены кодируют роль поверхности, а не её украшение. Компоненты опираются на смысловые алиасы — смена темы, режима или ветки автора не переписывает ни одного компонента. Ниже — все живые сущности и слои системы из cw.tokens.json + генераторных манифестов, отрендеренные реальными значениями.

Смысл CTA — не «купи сейчас», а «начать путь / увидеть план / выбрать поддержку / проверить пригодность». Один визуальный primary-класс для hero, pricing, next-step и sticky. Форма — soft rounded rect; min-height 3rem (touch target).

generator · token_packs.json

Масштабирование: территория автора = token pack

Пять именованных тем-паков. Каждый — 30 chrome-токенов (--cw-* + --cw-role-* + --cw-cta-*). Механизм даёт будущему автору/бренду собственную визуальную территорию без правки компонентов — переключатель вверху меняет только токены. activation deferred → LMS сейчас у паков ноль потребителей; активируется вместе с первым автором.

Правило изоляции: territories авторов не ссылаются друг на друга на лендингах — это граница авторов, а не только конверсионная дисциплина. Кросс-авторские переходы — marketplace-механика (revenue-share, согласие автора), только через email/сегмент по доша-тесту.

validation · npm run ds:qa

Governance

Восемь гейтов защищают систему. Источник правды — data/design-tokens/cw.tokens.json; globals.css — слой доставки, кодоген владеет base/delivery.

canon:guard
canon-файлы, preflight-sentinels, raw-hex allowlist + запрет локальных --cw-* в platform CSS, кросс-ссылки манифестов
tokens:check
кодоген JSON→CSS — no-op на чистом дереве (drift-гейт)
guard:ds-contract
--ds-* + landing контракты, required-floor --cw-sem-*/--cw-platform-*, запрет реинтродукции --cw-color-*, hero parity
guard:contrast
WCAG на парах text/CTA из токенов (body ≥ 4.5, large ≥ 3.0)
generator:validate + snapshot/determinism/language/rhythm
детерминизм генератора экранов
semantic:audit
route-family контракты, порядок блоков, alias-инварианты (existsSync-fail)

CenterWay Semantic Design System — сгенерировано из data/design-tokens/cw.tokens.json, data/generator/*.json, docs/design-system.md. Значения верны на момент сборки; источник правды — JSON + RAverse-канон Дизайн-токены.md.

Пять правил: 1) токены выражают метод, а не настроение · 2) экосистема — система путей, а не каталог офферов · 3) визуал = минеральное спокойствие + ясность маршрута + телесная достоверность · 4) доверие — отдельный токенный слой · 5) у каждого контекста свой режим.
