# Шлях 21: восстановление форматов, 2026-10-04

## Причина

Production обслуживался коммитом `1f6466bbc6176cb3aa5eeb39d2e5b28980bb08d2`,
а исходная рабочая копия находилась на более раннем коммите. Точный
production-коммит получен и использован для изолированной правки.

Production HTML содержал `formats: []`; запрос новых колонок к базе вернул
`42703: column experience_offers.early_amount does not exist`. Форматы не
удалялись: три активных одобренных предложения оставались в таблице.
Чтение Builder также запрашивало `early_amount` и `early_until` и падало.

## Восстановление

Уже записанная миграция `20261003150000_offer_early_price.sql` отрепетирована
через `npm run db:local:reset` на локальной БД с данными. Dry run показал
только эту ожидающую миграцию. Она применена через `npm run db:push`;
`check:migration-drift` подтвердил 102 production / 102 repo / 102 matched.
`npm run db:types -- --local` подтвердил уже соответствующие схеме типы
без изменения файла. Миграция не меняет цены, даты и режимы предложений.

После применения production-запрос новых колонок успешен для всех трёх:

| Код | Формат | Режим | Цена |
| --- | --- | --- | --- |
| `course:way21` | self | lead | 3900 UAH |
| `way21-group` | group | checkout | 4100 UAH |
| `way21-support` | individual | lead | 9000 UAH |

Колонки ранней цены пока `null`; скидка 3400 UAH из макета не настроена.
Кэш чтения форматов имеет TTL 300 секунд.

## UI preflight и правка

- `OfferSeam`: surface program page, semantic role orientation/progress;
  вопрос «где я в программе», token source global app DS, content source
  существующие подписи разделов, route boundary platform `/programs/*`.
  Только иконки и подписи; строка пояснения и её вычисление удалены.
  Boundary role: none для декоративного индикатора, существующая геометрия
  этапов сохранена. Неинтерактивный индикатор не имеет selection_family.
- `OfferFormats`: semantic role offer, вопрос «каким способом пройти курс»;
  token source существующие DS-рецепты, content source experience_offers,
  route boundary platform. Контролы не изменены; существующие кнопки оплаты
  и заявки — selection_family contour. Локальные ink-жесты не добавлены.
- Системная семантика, CTA и границы маршрутов не менялись. Это исправление
  одной поверхности и восстановление записанной схемы; RAverse не требует
  нового правила. Локальная DS-справка обновлена.
