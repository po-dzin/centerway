## 3. Что нужно сделать до первого объявления

### 3.1 Снять тихую паузу
`CW_META_TEST_MODE` в проде выключает сразу три вещи: ingestion инсайтов, телеграм-уведомления о лидах
и отчёты о подтверждённых продажах. Решение владельца: убрать переменную в Vercel (Production) и
передеплоить. Лучше — разделить на `CW_META_INGEST_PAUSED` и `CW_NOTIFY_PAUSED`, чтобы пауза рекламы не
глушила уведомления о продажах.

### 3.2 Остановить утечку
Кампания 120242755018100560 «Просування постів в Instagram» — ACTIVE, адсет «Качество жизни/… - 2»
с бюджетом 100 грн/день, 0 покупок за всё время. Пауза — одно действие API (`status=PAUSED`); делаю по
команде.

### 3.3 Дозагрузить историю и включить ручной синк
`ENABLE_MANUAL_META_SYNC=1` в проде + один запуск с `since=2026-02-01` — и вся история ляжет в
`analytics_meta_*` для отчётов и обучения правил.

### 3.4 Пересобрать аудитории под платформу
Website-аудитории (посетители, покупатели) собирались с воронок; с 22.08 покупка и кабинет живут на
`www`/`my`. Создать через API: «Покупатели 180 д» (событие Purchase на всех доменах), «Посетители
`/programs/*` 30 д», «Смотрели видео ≥ 50 %» — и от них LAL 1 % / 3 %.

## 4. Доступ, которого не хватает: Page и Instagram

Нужен только для органики и инсайтов профиля (публикация Reels из админки, статистика подписчиков,
комментарии). Для рекламы — не нужен. Порядок, всё делается руками владельца в Business Manager,
я не могу пройти его за вас:

1. business.facebook.com → Настройки бизнеса → Пользователи → Системные пользователи →
   «Conversions API System User» → **Назначить активы**: страница Facebook + Instagram-аккаунт,
   роль «Управление».
2. Там же → «Создать токен» → приложение 1467174895078197 → отметить
   `pages_show_list`, `pages_read_engagement`, `pages_manage_posts`, `instagram_basic`,
   `instagram_manage_insights`, `instagram_content_publish`, `business_management`.
   Срок — «никогда».
3. Сохранить как `META_PAGE_ACCESS_TOKEN` в Vercel (Production) и `.env.local`. Старый
   `META_ADS_ACCESS_TOKEN` оставить: у него роль только рекламная.
4. Проверка (я сделаю): `GET /me/accounts` должен вернуть страницу с `instagram_business_account`.

Если хочется видеть Ads Manager глазами (превью, отклонения модерации, диагностика доставки), это
можно делать через Claude in Chrome с вашей залогиненной сессией — но API покрывает 95 % задач,
и я бы не строил на этом процесс.

## 5. План: реклама, управляемая из нашего интерфейса

Принцип: **Meta — исполнитель, наша база — источник правды.** Всё, что запускается, сначала
записывается у нас (намерение, кто, когда, почему), потом уходит в API, потом сверяется с фактом.
Так же, как заказ рождается у нас, а WayForPay только подтверждает.

### Слой A — наблюдение (1–2 дня работы)
- Синк **структуры**, а не только инсайтов: таблицы `meta_campaigns`, `meta_adsets`, `meta_ads`
  (статус, бюджет, цель, таргетинг, креатив, посадочная), снимок раз в час + по требованию.
- Инсайты — как сейчас, плюс `since=02-01` бэкфилл и почасовой синк «сегодня» для активных кампаний.
- **Настоящий ROAS**: расход из Meta × оплаты из `orders` по `campaign`/adset-id, с чеком и продуктом,
  а не `purchase_value` из пикселя. Это единственная цифра, по которой стоит принимать решения.
- Экран «Промо» в админке: дерево кампания → адсет → объявление; сегодня/7 д/30 д; расход, CPA, ROAS
  (Meta и наш); свежесть данных; красные флаги.
- Алерты в Telegram (тот же тред): расход без покупок > N грн, CPA выше порога 2 дня подряд,
  ACTIVE-кампания без конверсионной цели, бюджет изменён не из админки.

### Слой B — управление с журналом (3–5 дней)
- Действия из админки: пауза/запуск, смена дневного бюджета, дубль адсета с другой аудиторией,
  замена креатива, создание кампании из шаблона (Advantage+ Sales, пиксель, Purchase, UA, 35–64,
  исключение покупателей).
- Таблица `meta_actions`: кто, что, параметры, ответ API, откат. Ни одного удаления — только пауза.
- Ограничители: потолок суммарного дневного бюджета, потолок на один адсет, «сухой прогон» перед
  первым запуском, двухшаговое подтверждение на создание.
- Загрузка креативов: видео из нашего хранилища → `advideos`, тексты и заголовки — из карточки
  курса (`lms_course_offers.pixel_content_name`, описание из билдера), чтобы объявление и посадочная
  говорили одно.

### Слой C — правила и агент (после двух недель данных слоя B)
- Правила в pg_cron: «CPA > X три дня → пауза», «ROAS > Y и частота < 2 → +20 % бюджета»,
  «креатив старше 21 дня и CTR упал на треть → сигнал на замену».
- Агентный контур: ночной разбор → **предложения** в админке (что, почему, ожидаемый эффект) →
  одобрение одним нажатием → применение через слой B. Автономия с лимитами — только после того,
  как предложения неделю подряд одобряются без правок.

### Что запускать в первую неделю (гипотеза, проверяется слоем A)
- Одна кампания Advantage+ Sales, UA, женщины 35–64, оптимизация Purchase, бюджет 500–800 грн/день.
- Лестница офферов: вход через reset-day (690) или short (795), апселл в natural-body / way21 письмом
  и в кабинете — ROAS считать по клиенту за 30 дней, не по первой покупке.
- 4–5 креативов сразу (три хука работали: «15 років остеопат», «лотоси», «тривожність»; добавить
  «розвантажувальний день» и «тест доші» как бесплатный вход).
- Посадочные — страницы платформы `/programs/*` с пикселем и CAPI, не старые воронки: тогда аудитории
  и атрибуция копятся там, где живёт продажа.

## 6. Рынок и API на сентябрь 2026 (веб-ресерч, источники в тексте)

**Бенчмарки.** Украинских цифр по нише wellness в открытых источниках нет; агентские диапазоны по Украине —
CPM 80–250 грн, CPC 3–12 грн. Глобально Health & Wellness — самая дорогая вертикаль (CPM ≈ $21,8, CPA ≈ $43),
медианный ROAS всех отраслей 1,9–2,2. Наши исторические CPM (≈ 270 грн) и CPA (≈ 550 грн ≈ $13) на этом фоне
нормальные; проблема была в чеке, не в аукционе. Ноябрь–декабрь CPM дорожает на 30–80 %.
([pricesua](https://pricesua.com/vartist-targetovanoi-reklamy-2026/), [lebesgue](https://lebesgue.io/facebook-ads/facebook-cpm-by-country),
[get-ryze](https://www.get-ryze.ai/blog/meta-ads-cpa-benchmarks-by-industry-2026), [Tinuiti Q1'26](https://www.karooya.com/blog/digital-ads-benchmark-report-by-tinuiti-q1-2026-key-highlights/))

**Что изменилось в Meta.** Advantage+ стал форматом по умолчанию: ручные настройки — это «выключение» автоматики.
Ранжирование Andromeda/Lattice ведёт таргетинг от креатива: рекомендация 6–15 разных концептов на кампанию,
ротация каждые 2–3 недели, широкая аудитория. Reels — треть показов Instagram, Explore как плейсмент упразднён,
Threads входит в дефолтные плейсменты. Окна атрибуции 7d/28d-view убраны, CAPI фактически обязателен (у нас есть).
Политики 2026 ужесточили «personal attributes» и health-claims — велнес-креативы отклоняют чаще; формулировки
«вам 40+ и болит спина» под риском. Для Украины: НДС не начисляется только при подтверждённом ФОП/VAT ID в Payment settings.
([1clickreport](https://www.1clickreport.com/blog/meta-advantage-plus-campaign-setup-2026), [confect](https://confect.io/tactics/meta-andromeda-2026),
[auditsocials](https://www.auditsocials.com/blog/meta-ad-policy-updates-2026-guide), [Meta Help VAT UA](https://www.facebook.com/business/help/181379050784377))

**Marketing API.** Текущая версия **v26.0** (июль 2026); всё ниже v24 отключено с 09.06.2026 — наш синк просит v21.0,
и Meta молча отвечает v25.0 (проверено заголовком `facebook-api-version`). Ставим
`META_GRAPH_API_VERSION=v26.0` явно. Отдельные Advantage+-эндпоинты закрыты с мая 2026: Advantage+ Sales создаётся
обычным `POST /campaigns` + adset и переходит в это состояние сам при CBO, `advantage_audience=1` и без исключения
плейсментов (`advantage_state_info`). Токен системного пользователя для создания кампаний — полностью рабочий
путь. Лимиты dev-тира: 300 + 40×активные объявления вызовов/час на аккаунт — нам хватает; Standard-тир даётся
автоматически при ≥ 500 вызовов за 15 дней.
