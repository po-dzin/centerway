# Каталог: единый редактор коммерческих условий форматов

## Решение

В «Ціни й доступ» форматы курса раскрыты по умолчанию. Для каждого
одобренного формата рядом находятся цена, прежняя цена, способ покупки
(чекаут / заявка), срок доступа, сохранение и переключатель продажи.
Базовый `course:<slug>` — такой же формат: у курса с лестницей предложений
нет второй формы базовой цены над списком. Метка курса «Бестселер» остаётся
на уровне курса, отличаясь от признака рекомендованного формата в Builder.

«Послуги й товари» заменяет неоднозначное «Пакети й заявки»: там только
самостоятельные предложения. Режим заявки — способ продажи, а не основание
для отдельного каталога цен. `way21-support` исключён по фактическому
владельцу предложения; историческая запись package не удаляется. Та же
проверка действует при записи, поэтому старый клиент не может изменить
цену/активность формата через products API. `irem-individual` по текущим
данным самостоятельная услуга; перенос к курсу не выполнен.

Сохранение условий одобренного формата не меняет active, review_status и
ожидающую ценовую заявку автора. Одобрение/отклонение и возвращение в продажу
остаются самостоятельными решениями. Нулевая цена при чекауте сохраняется
как free; пустая цена разрешена только для заявки. Срок заявки может
явно быть «Узгоджується після заявки»: это не бессрочный доступ. Переключение
на чекаут требует конкретного срока или явного бессрочного доступа. Старую цену нельзя
поставить ниже текущей, текущую — ниже настроенной ранней. Ранний тариф и
состав формата продолжают редактироваться в Builder. Для базового формата
срок синхронизируется с access_note курса. Уже выданный доступ не изменяется.

Ошибка чтения форматов блокирует редактор с повторным запросом; базовая цена
не показывается как подмена неполного списка. Cache purge использует курс,
определённый сервером по experience_id, а не переданный клиентом courseSlug.

## Preflight

Surface admin, route boundary `/admin/catalog` и существующие admin API.

- PricingRow: semantic role orientation/offer, вопрос «условиями какого курса
  управляю», content source catalog API, token source AdminRow/AdminControls
  и глобальные DS-токены. Boundary structural у общей панели.
- ProgramFormats/FormatRow: offer/boundary, вопрос «какие условия получает
  покупатель каждого формата», source experience_offers и предложения автора.
  Список без вложенных карточек: boundary none, существующие тихие разделители.
- ProductPricingTab: offer, вопрос «сколько стоит самостоятельная услуга или
  товар», source experiences + experience_offers. Историческая package запись
  не считается владельцем предложения, если предложение относится к курсу.
- Selection family: поля, select, Save/Approve/Decline/sale switch/disclosure
  contour; существующие tabs ink. Ink-кольцо на дочернем chevron disclosure
  удалено: это одна подписанная команда, не два независимых выбора.
- Временный результат: существующий useToast, без нового provider/баннера.
  Контролы используют общий no-selection; поля остаются редактируемыми.
- Палитра, типографика и material recipe сохранены. Impeccable polish в
  существующем мире Operate, без нового направления и декоративного redesign.

## Проверки

134 unit/route/существующих SSR-контрактных теста проходят. Включены защита
от изменения формата через products, сохранение inactive и pending proposal,
free/enquiry, сроки, validation, серверный владелец и cache invalidation.
Lint, typecheck и четыре guard:admin прошли. Production build проходит.
Локальная визуальная проверка выполняется на сборке с тестовой базой;
публикация кода и изменение production-цен не входят в этот цикл.

Итоговая браузерная проверка: 1440px — четыре равных поля по 275.5px;
390px — два столбца по 154px, без горизонтального переполнения. Шесть полей
сумм для трёх форматов, никакой второй формы базовой цены. Команды/select
имеют user-select none, числовые поля остаются selectable. В услугах три
самостоятельных записи; `way21-support` отсутствует. Сохранение сопровождения
из браузера записано в локальную БД: 9000 UAH, mode lead, active true,
access_days null / access_lifetime false; reviewed_at обновлён. Production
данные в этом админском цикле не изменялись. Повторные lint/typecheck/build,
134 теста, четыре admin guard и Prettier check прошли.

Next.js не имеет пакета `dist/docs` в установленной версии 16.1.5. Проверка
на production-сборке использует существующие API. Сборка для локального
браузера загружает `.env.development.local` через process.loadEnvFile перед
запуском npm, поскольку передача `node --env-file` в Next build приводит к
неподдерживаемому NODE_OPTIONS у worker. Примерные суммы локального снимка
отличаются от live; production-цены этим изменением не исправляются.
