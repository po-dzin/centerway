Технічне завдання: Універсальний шаблон сторінки програми (Marketplace + Hub)

Контекст завдання: 
Потрібно створити єдиний універсальний шаблон сторінки програми (курсу) для платформи Centerway. Платформа поєднує функціонал маркетплейсу (вітрина для продажу) та освітнього хабу (навчання). 
ВАЖЛИВО: На платформі ВЖЕ Є затверджений дизайн першого екрана (фонова картинка на весь екран, контент розташований зліва). Його структуру потрібно зберегти, додавши туди логіку перемикання станів.

Шаблон повинен підтримувати два стани (UI States) залежно від прав доступу користувача (hasActiveAccess).

1. Стан «До покупки» (Marketplace View)
Користувач не має активного доступу. Мета UI — конвертувати в покупку.

- Hero Section (Існуючий дизайн):
  * Фон: Зображення програми на весь екран (як зараз).
  * Контент (зліва): 
    - Хлібні крихти (Головна / Програми / [Назва]).
    - Заголовок програми (H1).
    - Короткий опис (1-2 речення).
    - Мета-теги (компактно під описом): Тривалість (напр., 3 дні), Формат (Аудіо/Відео), Термін доступу (напр., Доступ 30 днів після покупки).
  * Блок дії (під текстом зліва): 
    - Ціна.
    - Велика кнопка «Придбати доступ» (має викликати вже існуючу функцію checkout на платформі).

- Інформаційний блок (Bento Grid):
  * Сітка під першим екраном для швидкого читання (3-4 картки).
  * Картка 1: «Для кого» (2-3 марковані пункти).
  * Картка 2: «Результат» (2-3 марковані пункти).
  * Картка 3: «Формат та інструменти» (перелік).

- Програма / Структура (Syllabus Accordion):
  * Список модулів у вигляді акордеону.
  * У цьому стані біля кожного матеріалу (відео, аудіо, текст) стоїть іконка замка (🔒).
  * Клік по уроку не відкриває контент (заблоковано).

- Автор (Експерт):
  * Компактний блок: фото, ім'я, 1 речення про експертність для цієї програми.

- Cross-sell (Рекомендації):
  * Блок «Вам також може підійти» (2-3 картки інших програм внизу сторінки).


2. Стан «Після покупки» (Active Access View / Hub)
Користувач має активний доступ. UI сторінки миттєво адаптується для навчання.

- Hero Section (Зміни у лівому блоці):
  * Фон, заголовок та опис залишаються без змін.
  * Блок покупки (ціна та кнопка «Придбати») зникає.
  * На їхньому місці з'являється статус-бейдж: 🟢 Активна.
  * З'являється інформація про термін: «Доступ активний до [Дата]» + залишок днів.
  * З'являється головна кнопка «Продовжити навчання / Перейти до матеріалів» (скролить до списку уроків або відкриває останній пройдений).

- Програма / Структура (Зміни):
  * Іконки замків (🔒) зникають.
  * З'являються індикатори статусу уроку: пройдено (✅), поточний (▶️).
  * Назви уроків стають клікабельними лінками, які відкривають контент.


Вимоги до коду (для Claude):
1. Збережи існуючий layout першого екрана (fullscreen-background + text-left), адаптувавши лише кнопки та статуси.
2. Реалізуй шаблон через компонентний підхід (React/Vue або відповідний фреймворк).
3. Використай пропси для об'єкта Program (назва, опис, контент) та об'єкта Access (статус, дати початку/кінця).
4. Логіка рендеру кнопок, статусів та замків на уроках має цілком залежати від булевого пропсу (наприклад, hasActiveAccess).
5. Використовуй CSS-сітку (Grid) для секції Bento, щоб вона виглядала сучасно та мінімалістично.
