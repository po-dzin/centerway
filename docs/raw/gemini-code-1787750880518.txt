Технічне завдання: Адаптація шаблону для мобільних пристроїв (Mobile View)

Контекст:
Окрім десктопної версії, необхідно реалізувати бездоганний мобільний інтерфейс. Мобільна версія має фокусуватися на читабельності, зручних тач-зонах (мінімум 44x44px) та постійному доступі до головної цільової дії (Call to Action).

Вимоги до мобільного UI (UI States):

1. Стан «До покупки» (Marketplace View) - Мобільна версія

- Hero Section (Мобільний варіант):
  * Фон: Зображення на весь екран з затемненим градієнтом знизу (для читабельності тексту).
  * Контент: Вирівнювання по лівому краю, але займає 100% ширини. Хлібні крихти скорочені (напр. «Назад до Програм»). 
  * Мета-теги розташовані компактно в один або два рядки (іконка + текст).

- Sticky Bottom Bar (Закріплена панель внизу екрана):
  * ВАЖЛИВО: На мобільному телефоні кнопка покупки не повинна губитися при скролі.
  * Реалізувати закріплений (sticky/fixed) блок в самому низу екрана: 
    [Ціна] + Кнопка «Придбати» (займає більшу частину ширини).
  * Цей блок має плавно з'являтися, коли користувач проскролив Hero секцію.

- Інформаційний блок (Bento Grid на мобільному):
  * Замість сітки — вертикальний стек (1 колонка) або горизонтальний свайп-карусель (horizontal scroll) карток, щоб не розтягувати сторінку по вертикалі нескінченно.

- Програма / Структура (Syllabus Accordion):
  * Акордеон розтягується на всю ширину екрана.
  * Збільшені відступи для зручного натискання пальцем. 
  * Іконка замка (🔒) чітко видима справа.

2. Стан «Після покупки» (Active Access View) - Мобільна версія

- Hero Section:
  * Замість ціни під заголовком з'являється компактний бейдж 🟢 Активна.
  * Інформація про термін («Залишилось 30 днів») виводиться дрібним, але контрастним текстом.

- Sticky Bottom Bar (Зміна дії):
  * Закріплена панель внизу екрана змінює свій функціонал.
  * Замість ціни та покупки -> одна велика кнопка на всю ширину: «Продовжити навчання» (▶️).

- Програма / Структура:
  * Замки зникають.
  * З'являються чекбокси/індикатори (✅) зліва від назви уроку.

Вимоги до коду (для Claude) - Мобільна частина:
1. Реалізуй Sticky Bottom Bar (position: fixed; bottom: 0; z-index: 50) для мобільних екранів (breakpoint < 768px).
2. Забезпеч зміну контенту Sticky Bar залежно від пропсу hasActiveAccess.
3. Оптимізуй Bento Grid для мобільних екранів: flex-col або overflow-x-auto (горизонтальний скрол з приховуванням смуги прокрутки).
4. Переконайся, що фон першого екрана (Hero) має достатній overlay-градієнт, щоб білий текст не зливався з картинкою на маленьких екранах.
