# Read of the 2026-08-22 drift baseline — CenterWay

Hand-authored companion to `DS_DRIFT_2026-08-22.md`. The report is mechanical;
this is what the numbers mean. Nothing here has been fixed.

## 1. Zero conflicts — the derived export holds

Not one token where the mirror and the code disagree about a value. This is what
`ds-export.mjs` + `ds:sync:check` buy, and it is the difference between this
project and SymbolField's baseline, where 63 tokens conflict.

## 2. The 32 one-sided rows are one hand-written block

Every one of them is the code carrying a third value the mirror does not, and
they all come from the same place: `[data-dosha-test="true"]` in
`src/app/globals.css:1132` re-binds ~25 chrome tokens onto the platform tokens.

That block is not in `cw.tokens.json`, so the export cannot know the surface
exists. It is a modelling gap, not drift: the dosha-test skin is a real theme
layer living outside the token source. Either promote it to a mode pack under
`layers.modeOverrides` — where it would export like the others — or record in
`docs/design-system.md` that it is deliberately outside the token system.

## 3. Nine tokens ship that have never been in the mirror

`--cw-course-block-gap`, `--cw-course-body-size`, `--cw-course-heading-family`,
`--cw-course-heading-scale`, `--cw-course-heading-weight`, `--cw-font-data`,
`--cw-font-editorial`, `--cw-font-ui`, `--cw-branch-grid-discipline`.

The LMS course-typography layer landed in the code and sits outside the exported
layers. Small, but it is the leading edge of exactly the drift §1 prevents.

## 4. Fourteen mirror-only tokens are expected

`--cw-depth-*` and `--cw-component-glass-*` — the compatibility block
`docs/design-system.md` already documents as retired in the product and kept in
the project until its components migrate. The probe confirms the doc; no action
beyond finishing that migration.

## 5. One real brief↔code disagreement

`docs/design-system.md:419` describes the inverse material as the gradient
`#173027 → #274a3c`. The shipped token is:

```
--cw-mat-inverse-bg: linear-gradient(165deg, #182a20, #2c4635)
```

Neither stop matches. `#173027` survives only as a fallback literal in
`src/landing-static/shared/css/network-nav.css`. The document and the code
disagree about the darkest material in the system — fix the table, or the token.

The other eight brief-only hexes are prose, not claims: contrast-gate backdrops
(`#b0b0b0`), a measured failure being explained (`#d1cdc6`), landing-static
values that never enter `globals.css`, and values explicitly narrated as
superseded (`#588768`).
