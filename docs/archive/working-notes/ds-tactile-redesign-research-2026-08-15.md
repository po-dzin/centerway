# DS «тактильное стекло» — исследование перед редизайном (2026-08-15)

Статус: research / decision memo. Ничего из этого ещё не внедрено.
Компаньон: `ds-tactile-material-study-2026-08-15.html` — статичный этюд трёх ярусов материала на палитре платформы (открыть в браузере).

## 1. Постановка

Поворот: мини-сеть автора платформы (`way21`, `reset-day`, `dosha`, `consult`, `herbs`) **полностью сливается со стилем платформы**, а сам стиль платформы доводится до целостной ДС: экраны, компоненты, токены, изображения, иконки, ручная графика, паттерны. Направление — семантическая ДС остаётся, но становится «почти тактильной»: матовое стекло топбара расширяется на основные поверхности.

Уточнение границы (важно): в `docs/design-system.md` записано «Landing isolation is an author boundary — do not unify». Это правило про **Short/IREM** (другой автор). Пять лендингов сети — авторские страницы платформенного автора, их слияние с платформой правилу не противоречит. Short/IREM в этот редизайн **не входят** и остаются на своих `--landing-*/--product-*`.

## 3. Что такое «тактильность» здесь

Не «стекло везде». Стекло без иерархии убивает читаемость (WCAG-гейт `guard:contrast` сейчас считает контраст на **непрозрачных** парах — на стекле фон переменный) и дорого на мобильных (`backdrop-filter` на десятках элементов).

Предложение — **слой Material** с тремя ярусами и одним тёмным вариантом (см. этюд):

| Ярус | Материал | Где | Параметры (стартовые) |
|---|---|---|---|
| M0 | матовая непрозрачная | контент, текстовые блоки, формы, легал | тинт 92% `calm-surface`, без blur, светлый кант + внутренний штрих ink 8% |
| M1 | frost | топбар, карточки программ/офферов, чипы, sticky-CTA | тинт 74%, blur 18px, saturate 1.2 |
| M2 | deep frost | панели поверх фото (герой, попапы, шторки меню) | тинт 58%, blur 60px, saturate 1.35, тень 2 |
| M-dark | mineral dark + стекло 8% белого | офферные тёмные секции, hero-overlay | `#173027 → #274a3c` (единый с платформенным `mountain`) |

Общие тактильные приёмы: 1px светлый кант (`--mat-stroke`), внутренний highlight сверху (`inset 0 1px 0 white 70%`), двухслойная тень (контакт + рассеянная), едва заметное **зерно** (svg-noise, opacity ≈ .05) на канве — оно и даёт «матовость» вместо пластика; фон канвы — мягкие цветные подсветки warmth/guide/progress, чтобы стеклу было что размывать.

Обязательные правила материала:
- Гейт контраста для стекла: под текстом на M1/M2 всегда есть **гарантированный тинт-пол** (не ниже 58% surface), контраст считается против худшего фона (тинт над `--cw-platform-text`).
- `@supports not (backdrop-filter)` → M1/M2 деградируют в M0 с тем же тинтом 92%.
- `prefers-reduced-transparency` → всё в M0.
- Не более одного M2 в вьюпорте; M1 без вложенного стекла.
- Frost-image хак в шапке заменяется на честное стекло над реальным фоном (герой-фото и подсветки канвы уже дают материал для размытия).

## 4. Инвентарь для доведения ДС (что нужно определить)

**Экраны** (платформа): home, programs (список/деталь), products (список/деталь), dosha-test (интро/вопрос/результат), consult, herbs, expert, profile, pay/checkout, legal, auth-modal, admin (отдельная тема, dark). Плюс 5 лендингов сети. Плюс состояния: пусто/загрузка/ошибка/успех формы.

**Компоненты** — целевой единый набор ≈ 25 (сейчас 97 классов landing + ~15 block-типов платформы):
shell (topbar M1, burger-sheet M2, footer), hero (2 режима: dark-photo / light-split — второй нужен сети), section-head (kicker + serif h2 + lead), card (program / product / proof / problem), triad/step-rail, accordion (FAQ), author-block, offer-block (dark) + price-row, chip/badge, button (primary gold / ghost / tg), lead-form (+ modal), sticky-cta, testimonial-carousel, comparison (vs), stat-tile, note/boundary, lightbox, network-nav.

**Токены** — добавить слой `material` в `cw.tokens.json` (`--cw-mat-tint-{0,1,2}`, `--cw-mat-blur-{1,2,3}`, `--cw-mat-stroke`, `--cw-mat-highlight`, `--cw-mat-shadow-{1,2}`, `--cw-mat-grain`, `--cw-mat-dark-*`); свести `--cw-depth-*` и `--cw-component-glass-*` в него (сейчас это два полуслоя одного смысла); `--cw-net-*` перевести с копий значений на `var(--cw-sem-*)`.

**Типографика** — одна шкала для всего: сейчас `--ds-type-*` (платформа) и `--chip-fs/--sp-sec` (сеть). Решение по шрифту — см. §6.

**Иконки** — набор нет; нужен: один стиль (stroke 1.5, скруглённый, 24-сетка), ~30 глифов (тело/ритм/опора, дни, фазы, чек, стрелка, tg, галочка-гарантия, доши vata/pitta/kapha), как спрайт или React-компонент.

**Изображения** — правило фото: тёплая приглушённая цветокоррекция, один источник профилей (sRGB-теггинг — см. память про iOS-шов), два формата: полноширинный hero и still-life карточки; для сети — split-hero фото с M2-бейджами.

**Ручная графика** — эмблема, «путь»-линия (`--cw-sem-symbol-path`), волна/сияние героя, зерно, доша-глифы. Оформить как SVG-ассеты с токен-цветами.

**Паттерны** — секционный ритм (kicker → h2 → lead → grid), один CTA на экран, boundary-note после офферов, «где я / что за шаг / что дальше» из UI-UX канона.

## 5. Три пути слияния сети с платформой

| | A. Перепривязать токены, оставить `landing.css` | B. Пересобрать 5 лендингов как Next-страницы на платформенных блоках | C. Новый общий слой Material + рестайл `landing.css` под платформенные компоненты, разметка остаётся статичной |
|---|---|---|---|
| Что делаем | `--cw-net-*` → `var(--cw-sem-*)`, шрифт, кнопка | лендинги = `(platform)/way21` и т.д., блоки из `PlatformBlocks*` | `tokens:build` дополнительно генерит `shared/css/cw-material.css`; `landing.css` переписывается компонент за компонентом на новые токены/материал |
| Целостность | низкая: два набора компонентов остаются | максимальная | высокая: одна ДС, два рантайма |
| Риск | «те же цвета, другой продукт» — текущее состояние | большой: 14k px контента way21, checkout/lead-логика, статичный хостинг через `[brand]/[...path]`, SEO/скорость статических страниц | средний: объём CSS-работы, но без миграции контента и рантайма |
| Рекомендация | нет | позже, если LMS потянет за собой | **да, как этап 1–2**; B держим как горизонт |

## 6. Решения, которые нужны от автора (блокируют этап 1)

1. **Шрифт**: Manrope + Cormorant (платформа) на всю сеть — или Formular в платформу. Рекомендую первое: серифный заголовок — уже узнаваемая часть новой айдентики (`1924507`), Formular остаётся только у Short/IREM.
2. **Герой сети**: оставить светлый split-hero (лендинговый) как второй режим героя ДС, или переводить сеть на тёмный кинематографичный. Рекомендую **оба режима в ДС**, выбор по экрану (way21/reset-day — dark-photo с M2-панелью цены; consult/herbs/dosha — light-split).
3. **Степень стекла**: 3 яруса из §3 (рекомендую) или «стекло только на chrome + офферах».
4. **Кнопка**: pill (платформа) или soft-rect (сеть и `--cw-radius-btn` контракт). Сейчас в самой платформе противоречие: `--cw-radius-btn = soft` по доку, а hero-CTA — pill. Нужно одно.
5. Публичный **dark mode** — по-прежнему «нет по решению»? Material-слой проще проектировать сразу с dark-вариантом (админка уже dark).

### Решения автора (2026-08-15, вечер)

1. Шрифты — **платформенные** (Manrope + Cormorant Garamond + IBM Plex Mono) на всю сеть. Formular остаётся только у Short/IREM.
2. Визуал (фото/графика/иконки) — нужен отдельный глубокий ресерч; текущие платформенные still-life картинки — хорошая точка отсчёта. → `ds-visual-language-research-2026-08-15.md`.
3. Стекло — **один средний материал** (не слишком прозрачный, без супер-blur), с чуть теплом и грейном. Три яруса из §3 схлопываются: M0 матовый (без blur) + **M1 единственное стекло** + M-dark. M2 удалён.
4. Кнопка — **единый soft-rect везде** (`--cw-radius-btn = --ds-radius-button-soft`); pill у hero-CTA платформы — баг контракта, исправить.
5. **Dark mode учитываем сразу**: слой material проектируется парой light/dark, публичный dark становится возможным (решение о включении публичного переключателя — отдельно).

## 7. Предлагаемый порядок работ

1. Решения §6 → зафиксировать в `docs/design-system.md` (раздел Material + обновить правило про изоляцию: Short/IREM only).
2. Токены: слой `material` в `cw.tokens.json`, кодоген в `globals.css` + новый `shared/css/cw-material.css`; `--cw-net-*` → ссылки на `--cw-sem-*`; расширить `guard:contrast` на стеклянные пары; тесты `tokens:check`.
3. Платформа: shell (топбар без frost-image, M1), карточки/офферы на M0–M2, зерно канвы, кнопка, иконочный набор v1.
4. Сеть: `landing.css` компонент за компонентом (hero, cards, offer, accordion, forms, sticky) на те же токены; сначала пара `way21 ↔ reset-day`, потом dosha/consult/herbs.
5. Стайлгайд `design-system.styleguide.html` перегенерировать; визуальный дифф до/после по 10 экранам (скрипт снятия скринов — в этой сессии уже был).
